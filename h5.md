### Lab 0 – Buggy program

#### Lähtötilanne

Alkuperäisessä ohjelmassa funktion `buggy_function()` for-silmukka oli muodossa:

```c
for (int i = 0; i <= size; i++)
```
Ohjelman taulukossa oli viisi alkiota:

```int numbers[] = {1, 2, 3, 4, 5};```

Funktiolle välitettiin kooksi 5. Ohjelmaa suoritettaessa se tulosti myös ```Element 5: 0```, vaikka taulukon validit indeksit olivat 0–4. Koska taulukossa on viisi alkiota, indeksit alkavat nollasta ja viimeinen kelvollinen indeksi on 4.

#####Korjaus#####

Korjasin for-silmukan muuttamalla ehdon:

```i <= size``` 
muotoon:
```i < size```

Tämän jälkeen ohjelma käännettiin uudelleen GCC:llä ja suoritettiin.
